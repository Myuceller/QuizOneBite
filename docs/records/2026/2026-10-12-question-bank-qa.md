# 문제 은행 QA 및 테스트 DB 동기화

## 범위

2026-10-12 로컬 PostgreSQL의 게시 문제 364개를 대상으로 QA를 수행했다. 중지된 25개는 이번 내용 검수 대상에서 제외했다. 검수 스냅샷에는 문제 은행만 전달했으며 회원·인증·풀이 기록은 전달하지 않았다.

프로젝트에 [QA 스킬](../../../.agents/skills/quizquiz-qa/SKILL.md)과 사실·편집 검수자 설정 두 개를 추가했다. 역할·판정·실행법은 [QA 가이드](../../quiz/qa.md)를 따른다. 현재 세션에서 새 맞춤 역할의 로드 여부는 확인하지 않았으며, 이번 실행은 기존 에이전트 3개에 같은 기준을 전달해 122·121·121개씩 분할 검수했다. 각 문제를 두 명이 독립적으로 교차 검수한 것은 아니다.

- 전문 명칭 암기, 낯선 어휘, 질문의 정답 노출, 용어 명료화, 보기 형태 불균형도 개선 목록에 포함했다.
- 직접 출처 대조 결과 핵심 사실 부합 57개, 질문 전제 일부 불일치 1개다. 나머지 306개는 독립적인 출처 검증 미완료로 남겼다. 통과 판정을 사실 검증 완료로 해석하지 않는다.

- 질문 문자열 유사도로 추린 11쌍을 추가 검토했으며 같은 사실 중복은 발견하지 않았다. 전체 의미 중복의 완전한 전수 검증은 아니다.

개별 수정 사유·제안·출처·원본 스냅샷은 Git 제외 경로 `.local/quiz-generation/qa-2026-10-12/`에 저장했다. 핵심 보고서는 `adjudicated-private.json`, 원 검수 결과는 `review-1.json`~`review-3.json`이다. 사람의 독립 검수는 수행하지 않았다.

## DB 반영

- 대상: 기존 Render 무료 테스트 DB `quizonebite-staging-db`. 새 DB나 유료 리소스를 만들지 않았다.
- 기존 원격 게시 76개 + 신규 287개 = 게시 **363개**. 기존 중지 25개를 포함한 전체는 **388개**다.
- 로컬은 게시 364개·중지 25개 그대로다. QA에서 보류한 1개가 원격과의 의도적인 차이다. 로컬 Adminer는 원격 DB가 아닌 로컬 DB를 보여준다.
- 원격 기존 101개 행을 그대로 보존했고, ID가 같지만 내용이 다른 충돌은 없었다. 추가 이전 백업과 이후 스냅샷을 비공개 경로에 보관했다.
- 단일 트랜잭션으로 문제 은행만 추가했다. 기존 원격 중지 상태를 다시 게시하지 않으며, 플레이·회원·평가 기록은 동기화 대상이 아니다.
- 실제 동기화 계획으로 재실행 시 추가 0개임을 확인했다. 충돌 중단·검수 누락 중단·보류 제외·중지 보존 등을 검증하는 비공개 동기화 테스트 8개를 통과했다.

편집 경고가 있는 기존 로컬 게시 문제는 경고를 기록한 상태로 테스트 DB에 옮겼다. 이는 새 초안을 무검수 자동 게시한 것이 아니며, 모든 문제의 품질 개선을 완료했다는 뜻도 아니다. 긴 보기와 오답의 수정은 후속 개정 작업이다.

## 반영 후 확인

[테스트 사이트](https://quizonebite-staging.onrender.com)의 HTTPS API로 주제 5개 × 난이도 3개, 총 15개 필터에서 75문제를 출제·채점했다. 이번에 추가한 문제 52개가 실제 출제되었고, 정답·해설은 답변 전 숨겨지고 보기 섞기 후 정답도 올바르게 채점됨을 확인했다. 시험용으로 만든 계정 3개와 그 풀이 기록은 제거했다. 검증 중 문제 은행과 AI 생성 원장은 바뀌지 않았다.

DB 작업 동안 현재 작업 IP 하나만 일시 허용했고, 두 접속 작업 모두 종료 후 원래 빈 외부 접근 허용 목록으로 복구한 것을 Render API로 재확인했다. TLS 인증서 검증을 사용했다. 로컬 [Adminer](http://127.0.0.1:8080)는 HTTP 200으로 접근 가능했다.

맞춤 에이전트 TOML의 필수 필드·읽기 전용 설정, 스킬 YAML 헤더, 문서 상대 링크, `git diff --check`를 확인했다. 기본 스킬 검사기는 환경의 PyYAML 부재로 실행되지 않아 설치 없이 기존 `js-yaml`로 헤더와 필드 제약을 검증했다. 앱 코드·스키마를 변경하지 않아 앱 빌드 전체를 재실행하지 않았다.

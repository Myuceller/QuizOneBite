## 직접 작성·검수 방식

[상식 출제 기준](../../quiz/quality.md)에 따라 계산, 자격증·전공 시험형, 희귀한 숫자·이름 암기를 제외했다. 익숙한 대상과 일상 현상의 이유·차이·흔한 오해를 다루고, 모든 문항에 네 가지 보기·정답·해설·공개 출처를 저장했다. 같은 사실을 반복한 GPS 문항을 교체하고, 스위스와 덴마크 국기 모두에 해당할 수 있던 설명을 수정했다. 주제와 무관한 오답도 같은 분야의 개념이나 흔한 오해로 다듬었다.

생성 이력은 `provider: codex-editorial`, `promptVersion: editorial.general-knowledge.v1`, `apiCalls: 0`으로 구분했다. Astra API 생성 이력이나 사용 토큰을 꾸며 넣지 않았다. 최초 `verificationStatus: unreviewed`를 유지하고 별도의 `editorialReview`에 검수 시각, 기준, 문항 해시를 남겼다. Codex가 출처를 참고해 편집 검수한 것이며 별도의 사람이나 전문가가 독립 검수한 결과는 아니다.

기존 CLI로 모두 `draft`에 가져온 뒤 별도 트랜잭션에서 검수한 ID만 게시했다. 기존 112개 전체의 내용·상태를 대조해 변경하지 않았음을 확인했다. 정답이 포함된 초안·수정본·DB 전후 스냅샷은 Git에서 제외한 `.local/quiz-generation/editorial-2026-10-07/`에 파일 권한 600으로 보관한다. 이 자료를 정적 웹 파일이나 공개 저장소에 올리지 않는다. 스크립트는 당시 수량을 전제로 하는 일회성 운영 기록이며 재실행용 자동화가 아니다.

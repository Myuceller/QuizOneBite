# 짧은 보기 중심 출제 기준 — 2026-10-08

## 목적과 적용 범위

네 개의 긴 설명 문장을 읽는 부담을 줄이도록 보기의 기본 형태를 단어·이름·짧은 명사구로 정했다. 직접 작성 기준과 API 생성 공통 프롬프트에 반영했다.

## 변경

- 대부분 1~3어절, 가능하면 공백 포함 15자 안팎 이하를 권장한다. 의미가 필요한 고유명사 등을 기계적으로 자르지 않는다.
- 공통 상황은 질문에, 이유는 해설에 두고 문장형 보기는 예외로 제한한다. 긴 질문이나 생소한 전문 용어로 대체하지 않는다.
- 네 보기의 범주·문법 형태·길이를 맞추고 정답만 길어지는 문제를 검수한다.
- 생성 프롬프트 버전은 `quiz.v3`, `bank.evidence.v3`으로 갱신했다. 이전 생성 기록의 버전은 보존했다.
- 상세 정책은 [출제 품질 기준](../../quiz/quality.md), 운영 가이드는 [AI 생성](../../ai/generation.md)을 따른다.

## 검증과 남은 작업

AI 어댑터·Mock 관련 기존 테스트 42개와 diff 형식 검사를 통과했다. 테스트는 SDK Mock을 사용하며 실제 생성 결과의 문장 품질을 보증하지 않는다. 이번 작업에서 유료 API 호출이나 DB 문항 수정은 하지 않았다. 기존 문장형 게시 문제의 개별 수정·재검수와 실행 중인 Docker 앱에 새 프롬프트를 반영하는 재빌드는 별도 작업이다.

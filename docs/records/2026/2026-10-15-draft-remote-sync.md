# 신규 문제 원격 동기화·게시

사용자가 로컬 저장 후 원격 반영을 요청했다. 최초에는 기존 Render 테스트 DB `quizonebite-staging-db`를 대상으로 신규 초안 2,090개의 추가 계획을 만들었다. 문제·보기·정답·해설·출처·분류 메타데이터가 대상이며, 회원과 풀이 기록은 복사하지 않는다. 아래는 시점별 기록이며 실제 최신 결과는 마지막 절을 따른다.

- 누락 항목 추가, 재실행 중복 방지, 원격 게시 상태 보존, 내용 충돌 거부, 질문 중복 거부 및 게시된 로컬 항목 제외를 검증한 테스트 5개가 통과했다.

## 실제 반영 상태

**원격 쓰기는 실행되지 않았다.** 자동 승인 검토가 정답을 포함한 2,090개 초안을 Render 외부 DB로 전송하는 구체적인 데이터와 목적지에 대해 명시적 사용자 승인이 필요하다고 판정하여 실행을 차단했다. 승인 요청 전 비교와 준비는 완료됐으며, 실제 추가와 게시 전환은 0개다.

명시적 승인을 받은 뒤에는 원격 상태가 비교 시점과 일치하는지 다시 확인하고, 저장 전 백업·단일 트랜잭션·추가 내용 일치·기존 행 보존·재실행 중복 없음·임시 접근 회수를 검증한다. 이 기록은 실행 성공을 뜻하지 않는다.

## 비디오게임 마무리 후 전체 반영 요청

사용자가 비디오게임까지 완성한 뒤 DB 반영과 테스트를 요청했다. 최종 동기화 대상은 기존 2,090개 준비분을 포함한 신규 2,600개다. 기존 준비 스냅샷을 그대로 실행하지 않고 최종 검수본과 로컬 저장 내용, 원격 현재 상태를 다시 비교하도록 준비했다. 대상은 동일한 Render 테스트 DB이며, 문제·보기·정답·해설·출처·분류 메타데이터만 포함한다.

이전 자동 승인 차단 사유에 따라 대상 DB와 전송 내용을 명시하여 확인을 요청했다. 실제 출제 가능하도록 게시할지 초안으로만 저장할지도 함께 확인 중이다. 응답 전 원격 추가와 게시 전환은 실행하지 않는다.

검증 결과:

- 일반 테스트 106개, 격리된 임시 PostgreSQL 통합 테스트 33개 통과.
- 추가 전용 동기화 계획 테스트 5개 통과. 내용 충돌·질문 중복을 거부하고 기존 원격 상태를 보존한다.
- 원격 `/api/health`, `/api/health/ready`가 각각 200으로 응답했다.
- 비인증 플레이 조회·시작은 401, Origin 없는 시작 요청은 403으로 차단됐다. 이 확인은 신규 문제 반영 전 서비스 상태 검사이며 신규 문제의 원격 출제를 검증한 것은 아니다.
- 회원·풀이 기록을 원격에 복사하지 않는다. 실제 문제 원본과 검증 자료는 Git 제외 경로 `.local/quiz-generation/remote-final-2026-10-15/`에 보관한다.

### 14:35 KST 게시 완료

원격 접근 허용 목록은 원복했고 요금제 변경은 없다. 로컬 DB는 신규 2,600개를 초안으로 유지한다. 이번 작업은 원격 문제 은행 데이터 반영으로 앱 코드 재배포는 필요하지 않았다.

서비스 검증 도구가 처음에는 `provenance.taxonomy.subcategoryId`만 집계하여 분류별 20개 검사를 통과하지 못했다. 기존 28개는 소분류 ID 대신 `major`·`minor` 이름으로 분류를 저장한다. 원래 생성 계획과 동일하게 이 이름을 소분류 ID에 대응시키도록 검사 도구를 보정하고, 실제 게시 스냅샷에서 147개 조합 각각 20개임을 확인했다. 분류 문항은 2,940개, 분류 정보가 없는 기존 문항은 8개다. 신규 2,600개에는 소분류 ID가 모두 있으며 기존 28개 메타데이터는 그대로 보존했다. 이 과정은 검사 도구의 집계 보정으로, 문제나 앱을 수정하지 않았다. 현재 플레이 API는 기존 대분류·난이도로 필터링한다.

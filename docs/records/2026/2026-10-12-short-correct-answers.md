# 문장형 정답을 단답형으로 개정

## 범위와 기준

사용자의 정정에 따라 **정답으로 지정된 보기**가 문장 또는 긴 설명으로 된 문제를 검사했다. 오답이 길다는 이유만으로 정답이 이미 짧은 문항을 바꾸지는 않았다. 질문과 해설은 문장으로 유지할 수 있다. 정답은 단어·이름·짧은 명사구로 읽을 수 있게 하며, 긴 문장을 단순히 `~하는 것`으로 바꾸는 방법은 피했다.

로컬 게시 364개를 전수 검사했다. 기존 중지 문항 25개는 새 출제 대상이 아니므로 그대로 두었다. 작성자는 세 묶음으로 수정안을 만들고, 각각 다른 에이전트가 원문·개정안·정답·오답·해설을 다시 읽었다. QA 스킬의 역할 지침을 기존 에이전트에 전달해 실행했으며, 사람의 독립 검수는 아니다.

## 최종 결과

| 처리 | 문항 수 |
| --- | ---: |
| 기존 내용 유지 | 188 |
| 새 단답 버전으로 교체 | 160 |
| 대체 없이 출제 제외 | 16 |
| 검사 합계 | 364 |
| 최종 게시 | **348** |

개정 정답 160개는 모두 1~3어절, 최대 9자다. 개정 문항의 오답도 짧게 재구성했으며 모든 새 보기는 15자 이하다. 필요한 경우 질문의 방향을 바꾸어 원인·정의의 긴 설명 대신 핵심 개념·대상·현상을 고르게 했다. 기존 해설과 출처가 뒷받침하는 의미 범위를 유지했다.

독립 2차 검수는 승인 351개·수정 제안 13개였다. 그중 원래 짧은 정답을 불필요하게 바꾼 1개는 유지로 환원했고, 긴 개념 나열 1개는 추가 축약했다. 범주가 겹치는 오답, 수량 해석의 모호함, 조건이 부족해 다른 보기에도 해당할 수 있는 질문 등을 보완했다. 이전 QA에서 보류했던 분류 혼용 문제도 잘못된 전제가 제거된 개정본으로 반영했다.

출처의 사실을 새로 전수 검증한 작업은 아니다. 작성 단계에서 공식 도움말 원문 1건을 확인했으며 나머지는 기존 자료와의 의미 일치·문법·정답 단일성을 검토했다. 독립 검수자는 공개 출처 전체 재대조를 하지 않았다. 정의형으로 바뀌면서 체감 난이도가 낮아진 문항이 있을 수 있고 난이도는 여전히 편집상 잠정값이다.

## DB 반영과 확인

- 로컬: 기존 게시 176개를 `retired`로 변경하고 새 ID 160개 추가. 게시 348개·중지 25개·은퇴 176개, 전체 549개.
- Render 테스트: 기존 게시 175개를 `retired`로 변경하고 새 ID 160개 추가. 게시 348개·중지 25개·은퇴 175개, 전체 548개. 이전에 게시 보류되어 원격에 없던 원문 1개 때문에 전체 행 수만 다르다.
- 두 환경의 게시 ID·문제·보기·정답·해설·출처·분류가 일치한다. 기존 초기 데이터의 생성·검수 시각은 각 환경의 원래 값을 보존했다.
- 환경별 문제 은행 백업 후 단일 트랜잭션으로 반영했다. 기존 원문의 내용·출처·생성 이력은 유지하고 상태와 상태 변경 사유만 기록했다. 회원·기존 풀이 스냅샷·평가·신고는 수정하지 않았다.
- 각 환경에서 5개 주제 × 3개 난이도, 75문제 출제·채점 확인. 로컬에서는 개정본 31개, 원격에서는 개정본 32개가 실제 출제됐다. 교체·제외된 원문 노출은 0개, 보기 섞기 후 정답 연결 및 제출 전 정답 비노출을 확인했다. 검증용 계정은 환경별 3개씩 제거했다.
- 수정 계획의 중복 실행은 추가·은퇴 0건임을 확인했다. 내용 충돌, 중지 상태 보존, 중복 문제, 예상하지 못한 원문 누락 등의 검사 8개를 통과했다.
- 원격 작업은 현재 IP 하나만 일시 허용하고 각 작업 종료 후 원래 빈 허용 목록으로 복구했다. TLS 인증서 검증을 사용했다.

문제 원본·정답·개정 매핑·검수 보고서·백업은 Git 제외 경로 `.local/quiz-generation/answer-revision-2026-10-12/`에 있다. `plan-private.json`에서 원본 ID와 새 ID를 연결하고, `local-after-private.json`·`remote-after-private.json`에서 적용 결과를 확인한다.

Adminer의 현재 출제 목록은 `bank_questions`에서 **status = published**로 필터링한다. 은퇴 행은 과거 풀이와 수정 이력을 보존하기 위해 남는다. 이전에 시작한 게임과 풀이 기록은 당시 문장형 답이 남아 있을 수 있으며 새로 시작한 게임부터 개정 문항을 사용한다.

## 수량과 비용

5개 주제 × 3개 난이도는 모두 최소 5개 이상을 유지한다. 49개 소분류도 모두 남아 있으나 제외 후 AI·데이터, 기계·로봇, 돈·금융, 외국어·문자, 철학·사상, 동계·라켓 스포츠는 각각 4개, 세계의 생활·풍습은 3개다. 이번에는 부적합 문항의 제외를 우선했고 부족분을 새로 생성하지 않았다.

별도 생성·검수 AI API 호출은 0회다. 앱 코드·스키마 변경 없이 기존 서버의 문제 데이터를 갱신했다.

# 이미지가 필요한 문항 감사

## 범위와 현재 상태

Render 테스트 DB의 게시 문항 2,948개를 읽기 전용으로 조회했다. 이미지형은 기존 국기 식별 14개이며, 2026-10-15 적용 후 게시 수는 유지돼 있다. 이번에는 문제 내용·상태·플레이 기록을 변경하지 않았고 새 이미지를 만들거나 배포하지 않았다. DB 임시 접근은 조회 후 원복했다.

전체 2,948개에 스키마·중복·시각 정보 관련 표현 검사를 실행했다. 보기 수·보기 중복·정답 인덱스·분야·난이도 문제와 질문+이미지의 정규화 중복은 없었다. 텍스트 후보 455개에 지리의 나머지 문항 및 추가 표현으로 찾은 285개를 더해 **서로 다른 740개의 질문을 직접 읽었다**. 전체 2,948개를 사람이 읽듯 전수 의미 검토한 것으로 표현하지 않는다.

국기 외형으로 국가를 맞히는 14개는 전환됐지만, 국기 문양·구성·의미 문항에는 아직 그림이 없는 경우가 있다. 이전의 ‘국기’ 문자열 검색만으로는 성조기·태극기·유니언잭 등 다른 표현이 충분히 포함되지 않았다. 이번 검색에서는 이 표현과 조직 깃발까지 넓혔으며 스포츠 신호기·법적 맥락처럼 외형 식별이 목적이 아닌 문항과 구별했다.

## 독립 검토와 조정

우선 검토할 40개를 동일 ID·해시로 사실 역할과 편집 역할에 각각 전달했다. 두 역할 모두 40개 전부에 명시적 판정을 반환했고 조정자가 입력 해시와 범위를 확인했다.

- 사실 역할: 우선 전환 35개, 보조 5개. 공식 출처 직접 대조 4개, 미대조 36개.
- 편집 역할: 우선 전환 35개, 보조 3개, 글 유지/해설 이미지 2개. 출처 독립 대조 0개. 긴 조건·보기 표현 경고 2개.
- 두 역할이 함께 우선 전환으로 판단한 것은 34개다. 이동 경로를 읽는 문항은 말의 외형을 숨기는 조건으로 우선 전환에 포함하고, 누락된 영토를 찾는 문항은 누락 대상을 미리 강조하지 않는 보조 방식으로 유지했다.
- 최종 40개: **우선 전환 35개, 보조 3개, 글 유지/해설 이미지 2개**. 우선 35개는 전체 후보 128개에 포함된다. 나머지 후보 90개는 조정자 선별 단계이며 두 역할의 교차 검토를 받지 않았다.
- 확인된 현재 문항 사실 오류 blocker는 0개지만, 전체 문항 사실 인증이나 새 이미지 게시 승인이 아니다. 실제 이미지 정확성 검증은 아직 0개다. 같은 해협의 양안 국가와 연결 수역을 묻는 문항은 학습목표가 달라 중복으로 판정하지 않았다.

출처 대조는 [GINETEX 세탁 표시](https://www.ginetex.net/GB/labelling/care-symbols.asp), [ITF 2026 규칙](https://www.itftennis.com/media/7221/2026-rules-of-tennis-english.pdf), [NASA 해협 자료](https://science.nasa.gov/earth/earth-observatory/the-strait-of-gibraltar-151478/)를 이용한 4문항에 한정한다. 출처 확인은 이미지 이용 허락을 뜻하지 않는다. 사실 역할의 별도 경고 1개는 건축물 사진으로 바꿀 때 기존 형태 질문의 목표·정답이 달라질 수 있다는 점이다. AI 간 독립 검토이며 사람의 독립 검수가 아니다. 유료 AI API 호출은 0회다.

## 전환 방식과 후속 작업

먼저 지도에서 국가·해역·강·산맥을 지목하는 유형과 국기 문양, 악보·생활 기호를 전환하는 것이 적절하다. 위치를 길게 설명하는 본문은 ‘표시한 곳은?’처럼 줄이되, 두 대상을 묻는 기존 문항은 A/B 표시와 두 대상의 답을 유지한다. 국경선 위에 애매하게 화살표를 놓지 않고, 작은 수역은 확대한다.

그림이 기존 정답을 그대로 보여주는 경우에는 해설 이미지로 사용하거나 질문·보기·난이도까지 새로 검수한다. 지도·국기는 공개된 정확한 원본 자료를 확보하고 AI로 생성하지 않는다. 정답 라벨·파일명·대체 설명의 직접 누출을 막고, 모바일에서 표적과 기호를 읽을 수 있어야 한다. 이 원칙을 [출제 품질 기준](../../quiz/quality.md#외형위치기호는-이미지로-출제)에 반영했다.

다음 단계는 자산 출처·이용 조건 확인, 지도 표적 좌표 확인, 개정 질문·보기·난이도 검수, 실제 이미지와의 교차 확인이다. 현재 앱의 이미지 계약은 자체 호스팅 SVG이므로 실물 사진을 쓰려면 사진 형식 지원도 검토해야 한다. 실제 변경은 새 ID로 게시하고 기존 문항은 중지하며 기존 풀이 스냅샷을 보존한다.

후속 사용자 승인으로 우선 35개를 개정·게시했다. 실제 적용과 배포 결과는 [시각형 문제 개정 기록](2026-10-19-visual-question-release.md)에 별도로 정리했다. 위 감사 시점의 읽기 전용 결과와 구분한다.

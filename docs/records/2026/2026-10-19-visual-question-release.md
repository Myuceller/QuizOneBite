## 콘텐츠와 자산

- 교육용 도해 11개: 원근, 악보, 그래프, 경기장·말 이동, 등고선·등압선. 원 출처의 개념·규칙에 맞춰 축·음표·간격·경계 조건을 표시한 예시다.
- SVG 32개와 WebP 3개를 내용 해시 파일명으로 자체 호스팅한다. 출처와 이용 조건은 답 제출 후 출처에 포함한다. 유료 이미지·모델 API 호출은 0회다.
- 난이도 1개는 어려움에서 보통으로 조정했다. 실제 정답률로 보정한 난이도는 아니다.

## 검수

독립 사실·편집 에이전트가 동일 최종 내용 해시 35개를 검토했다. 사실 검수는 35개 모두 핵심 주장·정답을 원 출처와 대조했고, 편집 검수는 35개 본문·보기·해설·대체 설명과 개별 렌더를 확인했다. 최종 pass 35개, 미해결 blocker·warning 0개다. 한 지도의 표적 및 하구 연결과 한 문항의 난이도를 수정한 뒤 새 해시로 재검토했다. 출처 교체 1건도 양측이 새 해시로 확인했다.

이는 AI 간의 독립 검토이며 사람의 검수나 모든 지도 좌표의 측량 정확도 인증은 아니다. 이번 35개 안의 의미 중복과 전체 게시 스냅샷에 대한 정규화 질문·이미지 조합 중복을 확인했다. 전체 은행의 의미 중복을 다시 전수 검토한 것은 아니다.

## 구현과 로컬 확인

`0011_question_image_webp.sql`이 기존 SVG 계약에 정적 WebP를 추가한다. 기존 마이그레이션·문항·플레이 스냅샷을 다시 작성하지 않는다. `QuestionIllustration`에 이미지 확대 모달, 모바일 가로 스크롤과 안내, 닫기·Escape·초점 복귀를 추가했다. 이미지가 바뀌면 이전 파일의 실패 상태가 새 이미지에 전파되지 않는다.

- 로컬 임시 PostgreSQL 통합 테스트 48개 통과. SVG/WebP 저장, 채점·새로고침·복습·일일 문제 스냅샷 및 위험한 경로 거부 포함.
- 로컬 마이그레이션 적용 후 이전 35개 중단·새 ID 35개 게시 완료.

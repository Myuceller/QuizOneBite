# 홈 출제 설정 여백 조정

- 목적: 난이도 카드와 모드 제목이 붙고 카드 행 사이가 좁던 화면을 개선한다.
- 변경: 세 fieldset에 공통 인접 간격을 적용하고, 모드 제목 아래 간격을 추가했다. 카드 행·열 간격, 난이도·모드 카드 내부 여백, 시작 영역 위 여백을 함께 조정했다.
- 적용: 로컬 구현·검증 완료 후 기존 Render 테스트 서버 배포 흐름으로 반영한다. 실제 배포 결과는 GitHub CI·Render 배포 기록과 Git에서 제외한 로컬 작업 기록으로 확인한다.
- 검증: lint·typecheck·107개 기존 테스트·프로덕션 빌드 통과. 실제 Chrome 데스크톱·390px 모바일에서 시각적 간격 확인, 모드 클릭·방향키 선택·초점 테두리 확인. 390px·320px에서 문서 가로 넘침 없음.
- 범위: 화면 스타일과 공통 간격 클래스 정리만 변경. DB 마이그레이션·AI 호출·유료 API 비용 없음.

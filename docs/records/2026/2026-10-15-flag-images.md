# 국기 문항 이미지 전환

## 범위와 적용

국기 관련 게시 문항 23개를 확인하고, 외형으로 국가를 맞히는 14개를 공개 SVG 이미지형으로 개정했다. 의미·역사 등을 묻는 9개는 유지한다. 질문은 짧은 공통 문구로 바꾸고 보기·정답·해설·난이도는 유지한다. 자산 출처와 구현 계약은 [문제 은행](../../quiz/bank.md#이미지형-문항)에 정리했다.

로컬은 새 14개 게시·이전 14개 중지를 적용했다. 원격은 앱·이미지 배포 후 별도 트랜잭션으로 반영하며 기존 풀이와 일일 문제 스냅샷을 보존한다. 현재 이 기록 작성 시점에는 원격 배포 전이다.

## 검수

동일 ID·내용 해시의 14개 전부를 독립 사실·편집 역할에 전달했다. 사실 검수 14개 통과, 14개 출처 직접 대조, 보류·차단 이슈 0개다. 편집 검수는 13개 통과·1개 난이도 하향 제안이며, 이번에는 표시 형식 개정으로 범위를 정해 기존 난이도를 유지했다. 난이도는 실제 정답률로 보정되지 않은 잠정값이다. 편집 역할은 별도 출처 대조를 하지 않았으며 사실 검수 결과와 구분한다. 서로 다른 이미지의 공통 질문 문구는 중복 문항으로 보지 않는다.

14개 SVG를 브라우저에서 직접 확인했다. AI 간 독립 검수이며 사람의 독립 검수를 대체하지 않는다. 국가 제작 규격의 픽셀 단위 인증은 수행하지 않았다. 원본·정답·개별 검수 보고서·적용 전 백업은 Git에서 제외한 비공개 작업 폴더에 보관한다. 유료 AI API 호출은 0회다.

## 검증

- 일반 테스트 110개, PostgreSQL 통합 테스트 48개 통과. 이미지 스키마·중복·답안 비공개·일일 및 개인 풀이 스냅샷 보존을 검증했다.
- lint·typecheck·프로덕션 빌드 통과.
- 실제 로컬 브라우저에서 이미지 출제·채점·북마크 목록·결과 썸네일을 확인했다. 390px 모바일에서도 이미지 비율을 유지하며 화면 안에 표시된다.
- 테스트 계정의 풀이에만 없는 파일 경로를 설정해 이미지 로딩 실패 시 설명 대체 표시를 확인했다.

원격 배포 및 게시 확인 결과는 완료 후 이 기록에 추가한다.

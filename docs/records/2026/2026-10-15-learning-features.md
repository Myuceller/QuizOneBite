# 개인 학습 기능 4종

## 구현 범위

오답 복습, 분야별 성적, 오늘의 5문제와 참여 기록, 문제 북마크를 추가했다. 홈·풀이·결과·기록·새 학습 화면에 연결했다. 문제 내용이나 게시 상태는 바꾸지 않으며 AI·유료 API 호출은 없다.

새 마이그레이션 `0009_learning_features.sql`로 기존 데이터에 학습 저장 구조를 추가한다. 오답은 가장 최근 제출 기준, 성적은 모든 제출 기준이며 복습을 포함한다. 일일 문제는 한국 시간 날짜별 5개 공통 스냅샷과 계정별 한 세션을 보장한다. 세부 정책은 [문제 은행](../../quiz/bank.md#오답-복습북마크성적오늘의-5문제)을 참고한다.

## 검증

- 일반 테스트 108개, 격리된 PostgreSQL 통합 테스트 45개 통과.
- 오답 최신 상태·중복 제거·재정답 후 해제, 북마크 권한·반복 저장·목록 페이지, 분야 변경 후 과거 성적 보존, 계정 분리를 검증했다.
- 동시 일일 시작의 공통 문제·계정별 단일 세션, 완료 재요청, 미제출 정답 비공개, 원본 수정 후 스냅샷 보존, 게시 중지, 날짜 전환과 전날 이어 풀기를 검증했다.
- Chrome 실제 UI에서 임시 계정으로 일일 시작·이어 풀기, 오답 재도전 후 성적 갱신, 북마크 저장·목록·재도전·해제 흐름 확인. 데스크톱·390px 모바일 화면 확인, 320px 가로 넘침 없음.
- lint·typecheck·프로덕션 빌드를 확인하고 기존 Render 테스트 배포 흐름으로 반영한다. 배포 결과는 CI·Render 기록과 Git에서 제외한 작업 기록에 보관한다.

로컬 브라우저 검증에 사용한 임시 계정과 개인 풀이 기록은 검증 종료 후 정리한다. 일일 공통 묶음은 개인 기록과 별도로 유지한다.

# 문제 은행 부족분 재확인 — 2026-10-08

## 목적과 적용 환경

추가 문제 작성 전에 로컬 PostgreSQL의 현재 소분류·난이도별 게시 수량을 확인했다. 유료 생성 API 호출, 문제 내용·상태 변경, 원격 DB 반영은 하지 않았다.

## 확인 결과

- 게시 264개, 출제 중지 25개 유지.
- 기존 기준인 **49개 소분류별 합계 최소 5개**는 모두 충족하며 부족분은 0개.
- 소분류 × 난이도 조합 중 게시 문항이 없는 조합은 53개.
- **49개 소분류 × 3난이도 × 각각 최소 5개**로 기준을 확대하면 추가로 필요한 문항은 479개. 소분류가 없는 기존 문항은 계산에서 제외했다.

기존 목표 충족과 난이도별 추가 보강은 구별한다. 사용자에게 추가 기준을 확인 중이며 이번 점검 자체로 새 문제를 생성·게시하지 않았다.
